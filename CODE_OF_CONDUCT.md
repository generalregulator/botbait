# Code of conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

* Be respectful and constructive; critique code and ideas, not people.
* No harassment, discrimination or personal attacks.
* Security research is welcome. Contributions that facilitate attacks on third
  parties (offensive tooling, exploit code, attack automation) are not, see
  `CONTRIBUTING.md`.

Maintainers may remove comments, commits or issues that violate this code and
may block repeat offenders. Report conduct problems through the repository's
private channels (GitHub *Security* tab -> *Report a vulnerability*, or a
direct message to a maintainer).
